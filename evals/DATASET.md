# Evaluation Dataset Provenance

This document records the provenance, contamination properties, and deterministic verification
method for all **150 evaluation items** (`data/eval.jsonl`, 30 per slice), **25 disjoint pilot items** (`data/pilot.jsonl`, 5 per slice), and **21 hard-only calibration items** (`data/calibration.jsonl`).
All items are original and generated by `evals/build_dataset.py` (`uv run python -m evals.build_dataset`).

## 1. Split Separation & Determinism

- **`data/pilot.jsonl` ($N = 25$, 5 per slice, seed `20261101`):** Used strictly for pre-flight verification (checking tier separation, `Usage` token accounting, and container sandbox execution). Pilot items are **never** included in the evaluation split or 5-fold cross-validation.
- **`data/eval.jsonl` ($N = 150$, 30 per slice, seed `20261111`):** Main evaluation split, evaluated across all configured ladder `(model, thinking_level)` tiers.
- **`data/calibration.jsonl` ($N = 21$, seed `20261121`):** Only the capability-gated subtypes, used once per tier to confirm that the hard items separate the tiers before the full evaluation is run. Never used for training or evaluation.
- **Per-item seeding:** every item draws from its own `random.Random(f"{seed}:{item_id}")`, so changing one generator never changes another generator's items.
